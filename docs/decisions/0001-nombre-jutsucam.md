# 0001: Nombre "JutsuCam"

- Fecha: 2026-10-10
- Estado: aceptada

**Contexto:** el nombre provisional era "Naruto Video Call". "Naruto" es una marca registrada y el proyecto se publica en GitHub y LinkedIn.

**Decisión:** se llama JutsuCam. "Jutsu" es una palabra japonesa genérica que los fans entienden al instante.

**Consecuencias:** no se usa "Naruto" en el código, el repo, la documentación ni los assets.
